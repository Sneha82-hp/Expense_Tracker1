### 💰 Expenza — Personal Finance Management Platform

Expenza is a modern full-stack personal finance management platform designed to help users **track, manage, and analyze their financial activity** in one place.
Users can record income and expenses, categorize transactions, monitor spending patterns, and gain personalized insights to make more informed financial decisions.
The project focuses on combining **secure full-stack development, financial data management, analytics, and AI-powered insights** into a practical real-world application.

## 🔗 Live Demo 
[View Expenza](https://expense-tracker1-zeta.vercel.app/)

### 🌐 Real-World Use Cases

Expenza can be used by:
- 👤 Individuals managing their personal finances
- 🎓 Students tracking monthly expenses and budgets
- 💼 Professionals monitoring income and spending
- 📊 Users analyzing spending patterns and financial habits
- 💡 Users looking for personalized insights to improve financial decisions

### ✨ Key Features

### 🔐 Secure Authentication
- User registration and login
- JWT-based authentication
- Protected routes and API endpoints
- Secure password handling

### 💳 Income & Expense Management
- Add, edit, and delete financial transactions
- Categorize income and expenses
- Track transaction details and dates
- Maintain organized financial records

### 📊 Financial Analytics
- Interactive dashboard for financial overview
- Income vs. expense analysis
- Spending category insights
- Transaction-based financial summaries

### 🤖 AI-Powered Insights
- Analyze spending patterns
- Generate personalized financial insights
- Provide recommendations based on transaction behavior
- AI-powered receipt scanning to extract transaction details automatically
